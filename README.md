# AsistiApp 📋

**AsistiApp** es una aplicación web diseñada para simplificar la gestión de cursos y el registro de asistencia de alumnos. Su objetivo es ofrecer a los docentes una herramienta práctica, intuitiva y centralizada para administrar sus cursos, gestionar sus estudiantes y llevar un seguimiento de las asistencias.

## ✨ Funcionalidades

- 🔐 **Autenticación de usuarios:** registro e inicio de sesión.
- 📚 **Gestión de cursos:** creación, edición y administración de cursos.
- 👥 **Gestión de alumnos:** organización de los estudiantes de cada curso.
- ✅ **Registro de asistencia:** control de presentes, ausentes y llegadas tarde.
- 📝 **Edición de asistencias:** posibilidad de corregir registros anteriores.
- 📅 **Historial de asistencias:** consulta de los registros por fecha y curso.
- 👤 **Gestión de perfil:** administración de los datos personales del docente.

## 🎯 Objetivo del proyecto

Desarrollar una solución digital que agilice las tareas administrativas de los docentes, reduzca la complejidad del registro de asistencia y facilite el seguimiento de los alumnos.

## 🚀 Estado del proyecto

AsistiApp se encuentra en desarrollo. Las funcionalidades y características pueden cambiar a medida que avance el proyecto.

## 🎨 Diseño

La aplicación cuenta con una interfaz moderna, minimalista y adaptable, con el objetivo de ofrecer una experiencia de usuario sencilla y accesible.
